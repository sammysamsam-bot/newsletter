### Cloudflare agents can now create accounts, buy domains, and deploy

Cloudflare published a Stripe Projects integration giving AI agents the full lifecycle: sign-up, payment, infrastructure provisioning, code deploy. The autonomy frontier moves another notch — and the "agent-as-customer" abuse surface opens now. Expect a long tail of fraud, fake-business creation, and policy disputes as this primitive spreads to other PaaS providers. The ones that resist will be replaced by ones that don't, so the defense will have to land at the payments and identity layer rather than the deploy layer. ([Cloudflare blog](https://blog.cloudflare.com/agents-stripe-projects/))

### Chrome on Android adds approximate location sharing

Sites can now request a coarse location instead of GPS-precise. Small surface, real privacy delta — and a soft signal that browser vendors will break a long-standing default when user-trust pressure is high enough. The Apple/Google privacy competition is visible here: Google moved second, but they moved. Track whether this becomes the default request pattern in the wild within six months — the kind of change that quietly compounds, especially as iOS Safari pushes harder on the same axis. ([TechCrunch](https://techcrunch.com/2026/05/06/chrome-on-android-now-supports-approximate-instead-of-precise-location-sharing/))

### Ethos raises $22.75M from a16z for a voice-onboarded expert network

Thirty-five thousand experts onboarded weekly via voice AI — the headline number isn't the story. The angle is voice as the cost-per-onboard lever for B2B platforms generally: if voice can replace forms-and-questionnaires at this scale, every two-sided marketplace with an expert or seller side gets cheaper to bootstrap. Watch for copycat plays across legal-research, freelance, and consultant-matching markets in Q3-Q4 — the technology is no longer a differentiator, the data set you can build with it is. ([TechCrunch](https://techcrunch.com/2026/05/06/ethos-raises-22-75m-from-a16z-for-its-expert-network-with-voice-onboarding/))
