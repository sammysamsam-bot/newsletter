# Broadsheet

A daily editorial — flat newsprint, multi-section feed, broadsheet typography.

## Local dev

```
npm install
npm run dev
```

Site runs at `http://localhost:4321`.

## Build

```
npm run build
```

Outputs static site to `dist/`.

## How content lands here

This repo is the published archive. Briefs are generated by an upstream pipeline (see `~/.openclaw/skills/newsletter/`) every 3 days at 3 AM ET. The pipeline:
1. commits + pushes briefs to this repo (audit trail)
2. runs `netlify deploy --prod` from `dist/` directly to https://broadsheet-news.netlify.app

Auth/site config lives in `~/.openclaw/identity/netlify.env` (gitignored, mode 600).
Site ID: `ffc57c19-69e1-4a38-abed-7fcdbac8907c`. Admin: https://app.netlify.com/projects/broadsheet-news.

Content lives in `src/content/briefs/` as `<YYYY-MM-DD>-<category>.md` files. One markdown file per category per day.

`_aggregated/` is gitignored — that's the upstream pipeline's raw fetch cache, populated locally during generation, never committed.
