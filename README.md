# Broadsheet

A daily editorial — flat newsprint, multi-section feed, broadsheet typography.

## Local dev

```
npm install
npm run dev
```

Site runs at `http://localhost:4321`.

## Build

```
npm run build
```

Outputs static site to `dist/`.

## How content lands here

This repo is the published archive. Briefs are generated by an upstream pipeline (see `~/.openclaw/skills/newsletter/`) every 3 days at 3 AM ET. The pipeline (`skills/newsletter/scripts/publish.py`):
1. commits + pushes briefs to this repo (audit trail), mirrored to `sammysamsam/newsletter` (the Vercel source)
2. `apphost deploy newsletter` rebuilds `dist/` and serves it privately over Tailscale at `https://sammybots-macbook-pro.tail5e4166.ts.net:8443`
3. `pdf_post.py` renders the day's issue (`/issues/<date>`) to PDF and posts it to the `#newsletter` Discord channel

Skip the deploy leg (e.g. testing): `publish.py --no-deploy`. Skip just the PDF: `publish.py --no-pdf`.

**Public host: Vercel** — `https://newsletter-pink-beta.vercel.app` (canonical URL, set as astro `site:`), deployed from `sammysamsam/newsletter`. Tailscale (apphost) serves the same build privately. The Discord PDF post uses the openclaw bot token from `~/.openclaw/openclaw.json`.

Content lives in `src/content/briefs/` as `<YYYY-MM-DD>-<category>.md` files. One markdown file per category per day.

`_aggregated/` is gitignored — that's the upstream pipeline's raw fetch cache, populated locally during generation, never committed.
